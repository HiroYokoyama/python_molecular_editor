# AI Usage in MoleditPy Development

This document records the generative AI tools and models used while developing MoleditPy, and the scope of that use. It is the authoritative list; the project's paper cites this page rather than enumerating every version, so that the record can be kept current without amending the manuscript.

The author manually reviewed and verified all AI-generated code and documents, and retains full intellectual responsibility for the software's architecture, security, and scientific accuracy.

---

## Scope of Use

AI assistance was applied to:

- Code generation and refactoring
- Test authoring
- Documentation drafting
- Initial drafting of the project's manuscript

Every change was reviewed by the author before being committed. Design decisions, the plugin API contract, and all scientific claims are the author's own.
