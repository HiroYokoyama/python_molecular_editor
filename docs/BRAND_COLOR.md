# Brand Color

## MoleditPy Blue

| Hex | RGB |
|---|---|
| `#3577F7` | `53, 119, 247` |

Use this exact hex for any MoleditPy-branded accent, instead of picking a
similar-looking blue.

## Where it's used

- Nitrogen's default CPK color — `moleditpy/src/moleditpy/utils/constants.py`, `CPK_COLORS["N"]`
- The file icon's "MoleditPy File" bar — `icon_images/file-icon/`, generated by `scripts/generate_file_icon.py`
