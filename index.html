MoleditPy v4

A continuous molecular workspace途切れない分子ワークスペース

Draw it. Shape it. Make it useful.描く。形にする。計算へつなげる。

MoleditPy brings 2D sketching, interactive 3D geometry editing, and computational-chemistry preparation into one programmable desktop workspace.MoleditPyは、2D構造の描画、対話的な3D幾何編集、計算化学の準備を、拡張可能なひとつのデスクトップ環境にまとめます。

01 / One continuous workspaceひとつながりの作業環境

Stay with the molecule from first bond to final file.最初の結合から最終ファイルまで、分子とともに作業できます。

01

Sketch a structure構造を描く

Build molecules with ring templates, chains, stereochemistry, charges, and the full periodic table.環テンプレート、鎖、立体結合、電荷、周期表を使って分子を構築します。

02

Shape it in 3D3Dで形を整える

Generate conformers, drag atoms in the viewport, set exact geometry, and optimize with MMFF94 or UFF.配座を生成し、3Dビューで原子を操作し、精密な幾何を設定してMMFF94またはUFFで最適化します。

03

Check, export, continue確認して、出力し、次へ進む

Inspect molecular properties and move into calculation or publication workflows with practical file exports.分子特性を確認し、実用的なファイル出力で計算や論文作成の工程へ進めます。

01 / 2D Canvas

Intuitive 2D Drawing 直感的な2D描画と編集

Draw and edit molecular structures with simple mouse controls on a responsive PyQt6 canvas. PyQt6によるモダンで軽快なキャンバス上で、原子や結合を直感的なマウス操作で描画・編集できます。

  • Benzene and 3–9 membered ring templates with live preview
  • Alkyl chain tool with automated 15° angle snapping
  • Full periodic table element selector
  • Formal charges, radicals, and stereochemical bonds
  • Fragment clipboard operations (Cut, Copy, Paste)
  • ベンゼン環や3〜9員環のテンプレート（二重結合自動配置）
  • アルキル鎖ツール（固定結合長・15°刻みスナップ）
  • 周期表ダイアログからの全元素選択
  • 形式電荷・ラジカル・立体結合（Wedge/Dash）の素早い設定
  • 分子フラグメントのカット・コピー・ペースト完全対応
02 / 3D Modeling

Interactive 3D Editing 3D可視化と高度な幾何編集

Conformation generation and fine-grained geometric adjustments directly in the 3D viewport. RDKitによる2D-3D変換と、3Dビュー内で原子を直接ドラッグ操作できる本格的な配座調整ツール群。

  • Direct 3D atom dragging for intuitive conformation editing
  • Exact numerical setting for bond lengths, angles, and dihedral angles
  • Axis alignment, best-fit plane projection, and mirroring
  • MMFF94 / UFF force field optimization with geometric constraints
  • Ball & Stick, CPK, Wireframe, and Stick visualization styles
  • 3Dビュー内の原子直接ドラッグによる直感的な配座作成
  • 結合長・結合角・二面角の精密な数値指定編集
  • 軸整列・最適フィット平面投影・鏡像作成ツール
  • 距離・角度・二面角を固定した制約付き力場最適化 (MMFF/UFF)
  • ボール＆スティック、CPK空間充填、ワイヤーフレーム、スティック表示
03 / Analysis & IO

Analysis & Export 解析とファイル入出力

Compute molecular properties and export structures to computational chemistry software. 分子特性の自動計算から、DFT計算ソフト・3Dプリント・論文発表向けのエクスポートに対応。

  • Calculated properties: formula, weight, SMILES, LogP, TPSA
  • Automatic chiral center recognition with R/S labels in 3D
  • Format support: MOL, SDF, XYZ, SMILES, and InChI
  • 3D printing support: STL and OBJ/MTL export
  • High-resolution publication image export (PNG & SVG)
  • 分子特性解析（分子式・分子量・SMILES・LogP・TPSA等）
  • キラル中心の自動認識と3DビューでのR/S立体化学ラベル表示
  • MOL、SDF、XYZ、SMILES、InChI のインポート・エクスポート
  • 3Dプリント・レンダリング向けの STL / OBJ / MTL 出力
  • 論文・発表向け高解像度 PNG（2D/3D）および SVG（2D）出力
04 / Extensibility

Programmable Python Plugins プログラマブルな拡張性

Extend the editor with custom scripts and browse community-contributed plugins. Pythonスクリプトを配置するだけで機能を追加できるプラグインシステムとコミュニティ連携。

  • Drop-in Python scripts that integrate directly into the application menu
  • Discover add-ons on the Plugin Explorer
  • Direct access to MainWindow, RDKit molecule, and Qt graphics items
  • Ideal for automating repetitive workflows and algorithm prototyping
  • スクリプトをフォルダに入れるだけで即メニュー化するプラグイン機構
  • Plugin Explorer から特化プラグインを直接探索・入手可能
  • MainWindow、RDKit分子、Qtシーンへの完全なAPIアクセス
  • 独自の計算化学ワークフロー自動化や新アルゴリズムの検証に最適

Install with pip. Start editing. pipでインストールして、編集を始める。

Use pip on Windows, macOS, and Linux for the complete, recommended installation. Windows、macOS、Linuxでは、完全な機能セットを利用できるpipでのインストールを推奨します。

Recommended: Python / pip
# 1. Install MoleditPy # 1. MoleditPyをインストール
$ pip install moleditpy-installer
# 2. Create an application shortcut # 2. アプリケーションショートカットを作成
$ python -m moleditpy_installer
