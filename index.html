MoleditPy

A programmable and cross-platform molecular editor built in Python.
Streamline your workflow from 2D drawing to 3D visualization — an ideal tool for rapidly preparing DFT calculation inputs.

📖 User Manual ⚡ Quick Install GitHub

Core Features

✏️

Intuitive 2D Drawing

Draw and edit molecular structures with simple mouse controls on a PyQt6-powered canvas.

  • Ring templates (benzene, 3–9 membered rings) with live preview
  • Alkyl chain tool with auto-snapping
  • Full periodic table element selection
  • Charges, radicals, stereochemical bonds
  • Cut / Copy / Paste for molecular fragments
🧊

Advanced 3D Editing

Generate 3D conformations and perform precise geometric manipulation directly in the 3D view.

  • Interactive atom dragging in 3D
  • Set bond length, angle, and dihedral angle
  • Alignment, planarization, and mirroring
  • Constrained MMFF/UFF optimization
  • Ball & Stick, CPK, Wireframe, Stick styles
📊

Analysis & Export

Calculate molecular properties and export structures for DFT calculations, 3D printing, and more.

  • Molecular formula, weight, SMILES, LogP, TPSA
  • R/S stereochemistry labels in 3D view
  • Import/Export: MOL, SDF, XYZ, SMILES, InChI
  • Export 3D models as STL or OBJ/MTL
  • High-resolution PNG/SVG image export
🔌

Programmable & Extensible

Extend MoleditPy with Python plugins — full access to the application API and RDKit objects.

  • Drop-in Python plugin system
  • Plugin Explorer — discover & download plugins
  • Full API access to MainWindow, RDKit mol, Qt scene
  • Ideal for rapid prototyping of new algorithms
